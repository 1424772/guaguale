# 第 6 款刮刮卡《深海打捞》设计草案

> 状态：v0.1。海盗沉船主题、售价、2×4 布局、图案和最高价值兑奖规则已确认；概率为待确认草案；概念图 v1 已生成待确认。

## 1. 定位

- 名称：《深海打捞》。
- 固定售价与动态购买门槛：80000 金币。
- 视觉主题：从沉没的海盗船船舱中打捞物品，使用深海蓝、青绿色荧光、旧木和黄铜材质。
- 卡面形态：横版，中央严格设置 2 行 × 4 列，共 8 个舷窗式打捞刮格。
- 支持手动刮奖和机器人刮奖。

## 2. 最高价值物品兑奖

- 8 个打捞格各刮出一个海底物品。
- 全部刮开后，只按照其中价值最高的物品兑奖一次；所有格子的金额不相加。
- 相同物品出现多次不翻倍、不累计。
- 每张卡最多出现一个盈利图案，即“黄金宝箱”或“海神王冠”；两者不会同时出现，也不会重复出现。
- 服务端先按概率抽取本张卡的最高价值图案，将其随机放入一个打捞格，再使用价值更低的图案填充其他 7 格并打乱。
- “空网”是 0 金币填充图案，不单独作为最高奖项档位；最低档卡至少包含一个海草团。
- 客户端只负责刮除、比较展示和动画，开奖及布局生成由服务端完成。

采用最高价值兑奖而不采用八格累加，是为了确保只有两个指定图案能够产生净盈利；否则多个低价值物品相加也可能超过售价。

## 3. 图案、奖励和盈亏

| 图案 | 兑奖金额 | 相对售价 | 实际盈亏 | 结果性质 |
| --- | ---: | ---: | ---: | --- |
| 空网 | 0 | 0x | -80000 | 仅作为填充图案 |
| 海草团 | 10000 | 0.125x | -70000 | 亏损 |
| 破皮靴 | 20000 | 0.25x | -60000 | 亏损 |
| 漂流瓶 | 32000 | 0.4x | -48000 | 亏损 |
| 生锈船锚 | 56000 | 0.7x | -24000 | 亏损 |
| 珍珠贝 | 72000 | 0.9x | -8000 | 亏损 |
| 黄金宝箱 | 120000 | 1.5x | +40000 | 盈利 |
| 海神王冠 | 240000 | 3.0x | +160000 | 头奖 |

只有黄金宝箱和海神王冠两种图案能够获得高于购卡成本的奖励，最高兑奖金额为售价的 3 倍。

## 4. 概率与金币经济草案

下表概率指“该图案是整张卡最高价值物品”的概率，不是每个打捞格独立出现该图案的概率。

| 最高价值图案 | 无好运基础概率 | 满级好运概率 |
| --- | ---: | ---: |
| 海神王冠 | 3% | 6% |
| 黄金宝箱 | 8% | 18% |
| 珍珠贝 | 20% | 26% |
| 生锈船锚 | 24% | 22% |
| 漂流瓶 | 20% | 13% |
| 破皮靴 | 15% | 9% |
| 海草团 | 10% | 6% |

- 无好运时理论平均奖励为 55040 金币，理论返奖率为 68.8%。
- 满级好运时理论平均奖励为 73600 金币，理论返奖率为 92%。
- 无好运时产生净盈利的概率为 11%，满级好运时为 24%。
- 好运升级时，概率从低价值打捞物逐步转移到珍珠贝、黄金宝箱和海神王冠。
- 卡片正面不印概率；独立规则详情中的各档概率必须与服务端实际开奖配置一致。

## 5. 视觉与交互建议

- 8 个刮格使用船舱舷窗或加固货舱门造型，但银色刮层必须一眼可辨。
- 每刮出一个物品，当前“最高打捞价值”即时更新；更高价值物品出现时播放短促替换动画。
- 第 8 格刮开后锁定最高价值图案；卡片仍需拖入兑奖区域后才能结算。
- 所有物品依靠轮廓和材质区分，不只依靠颜色。
- 正式网页中的标题、售价、规则、图案名称和奖金由 HTML/CSS 渲染，概念图中的文字不直接作为最终资产。
