# 《永恒彩钻》动画规格

> 版本：v0.1
> 对应玩法文档：`docs/game-07-draft.md`

## 1. 动效定位

八款卡中最精致的珠宝鉴定体验。以珍珠白、冰银、淡紫、浅蓝和微粉虹彩为主，强调克制的折射与鉴定仪式，不做赌场式闪烁。

## 2. 待机动画

- 中央彩钻做 8–12 秒一轮的极缓慢视差偏转，旋转幅度不超过 3°。
- 每 6–8 秒有一道窄虹彩折射扫过钻石，持续 800–1000 ms。
- 铂金边框使用低亮巡游微光；背景小钻随机单点星芒，同屏高亮不超过 6 个。
- 五个鉴定刮格保持同等亮度，不暗示某项等级。

## 3. 刮开与单项鉴定

- 刮动产生铂金粉末和透明碎晶，粒子在 600 ms 内消失；单格同屏不超过 16 个。
- 用户可在五项鉴定间任意刮动；单格达到 65% 后保留未刮涂层，等级图标以 0.9 倍缩放与 450 ms 光环反馈。
- 刮格内部只显示等级图标，不显示等级名称、金额或概率。
- 光环颜色只能依据已经揭示的图标；未公开的四项不得预加载不同可观察动画时延。
- 每揭示一项，中央鉴定环填充 1/5，但不显示当前最低等级或预计奖金，避免提前结束判断。

## 4. 整片刮层达到累计阈值与八级结果

- 整片刮层累计达到 65% 并统一清层后，用 300 ms 逐项扫描五枚图标，再将最低等级图标复制到最终鉴定印章区。
- 非最低项降低至 78% 亮度，决定最终等级的一个或多个最低项保留全亮描边。

### 裂纹级

- 中央彩钻表面出现一条非破碎式细裂纹光线，虹彩熄为冰灰；时长 450 ms。

### 工业级

- 钻石降低透明度并呈粗面磨砂光，使用一次低音鉴定章声。

### 珠宝级

- 切面恢复清晰，出现一轮淡蓝边光，时长 500 ms。

### 稀有级

- 银环从外向内收束并盖下“鉴定完成”印章，使用稳定清脆音表示保本。

### 精选级

- 增加一次淡粉—浅蓝折射，三个小星芒依次出现。

### 典藏级

- 紫银棱镜光绕钻石半圈，底座微微升起 5 px，时长 700 ms。

### 皇室级

- 皇冠形铂金光环从钻石后方升起，边框转为金白，出现不超过 18 个碎晶粒子。

### 永恒级

- 无限光环在钻石后形成，播放一次约 1.2 秒的环形棱镜爆光和金白粒子扩散。
- 不做全屏频闪；峰值亮度持续不超过 120 ms；完整动画不超过 1.4 秒且可跳过。

## 5. 兑奖动画

- 服务端兑奖成功后，五项鉴定图标汇入中央彩钻，卡片折叠成一张珠宝证书并滑入兑奖区，时长 600 ms。
- 皇室级和永恒级可在余额更新后保留 300 ms 的小型星芒尾效，其余等级不保留尾效。
- 兑奖失败时证书展开回原卡片，保留已刮状态。

## 6. 机器人版本

- 机器人依次扫描重量、切工、净度、火彩、稀有度，每格只保留 100 ms 图标揭示。
- 最终扫描五项和印章压缩到 350 ms；皇室/永恒只保留一轮边框光，不播放长棱镜爆光。

## 7. 性能与无障碍

- 默认使用 CSS 变换、渐变遮罩和共享轻量 Canvas 粒子，不引入大型 3D 引擎。
- 移动端粒子减半并限制模糊半径；低性能模式用预渲染高光替代实时折射。
- 减少动态模式关闭视差、巡游光、裂纹移动和粒子，只保留 150–200 ms 图标/结果淡入。

## 8. 验收

- 五个刮格内始终只有图标。
- 最终等级严格取五项最低等级；相同最低项可以同时高亮，但只兑奖一次。
- 未完成五项前不显示预计档位或奖金；跳过动画不会改变最终等级。
