# 《放手一博》动画规格

> 版本：v0.1
> 对应玩法文档：`docs/game-08-draft.md`

## 1. 动效定位

全套卡中最克制、最压迫的终局演出。只有一个死神徽记刮区，三个结果分别用“熄灭、冷银切光、白金开启”表达，不显示概率，不使用好运效果。

## 2. 待机动画

- 死神徽记外圈每 4 秒进行一次极弱暗红呼吸，亮度变化不超过 8%。
- 背景最多保留 10 个缓慢灰烬粒子，不卡片旋转，不做镜头逼近。
- 骷髅、镰刀和天使素材使用相同预载策略；待机动画和资源时序不得泄露结果。
- 好运道具的全局光环不得覆盖本卡，本卡始终显示“好运无效”。

## 3. 刮开过程

- 单一圆形刮层使用 Canvas 2D 遮罩；轨迹产生枪灰金属屑和少量灰烬。
- 刮除面积低于 70% 时只播放通用刮擦反馈，不出现红、银、白金结果专属光效。
- 达到 70% 后在 180 ms 内补间清除剩余涂层，然后读取已锁定结果并播放对应动画。
- 刮奖过程中离开页面时保存遮罩进度；恢复后仍是同一图案。

## 4. 三种结果动画

### 骷髅：0 金币

- 暗红外圈从外向内熄灭，骷髅眼部只闪一次极弱灰光。
- 卡片向下震动一次，幅度不超过 3 px；灰烬缓慢落下。
- 结果区显示 0 金币，总时长约 800 ms；音效为短促空洞低音。
- 不先闪现镰刀或天使，也不播放虚假接近大奖效果。

### 镰刀：300000 金币，保本

- 一道冷银弧光从左下划向右上，镰刀图标沿弧线成形。
- 外圈暗红转为冷银，结果区显示返还 300000 金币，总时长约 1 秒。
- 音效为一次金属切割和短确认音，不使用大奖庆祝。
- 金币要在拖入兑奖区且接口成功后恢复，刮开动画阶段不改余额。

### 天使：3000000 金币

- 背景由纯黑过渡到深海军蓝，一道窄白金光从徽记中央打开。
- 光翼展开、光环上升，边框转为白金并扩散一圈光波；粒子以少量羽片和光点为主。
- 结果区显示 3000000 金币，总时长约 1.8 秒，可点击立即跳过。
- 音效为低冲击、玻璃泛音和极短合唱气声，不使用现金或老虎机音效。
- 实际金币仍仅在兑奖成功后入账。

## 5. 兑奖动画

- 骷髅卡拖入兑奖区时弹回并提示“该卡未中奖，无法兑奖”。
- 镰刀卡兑奖成功后，冷银弧线卷起卡片进入兑奖区，余额平滑恢复到服务端返回值。
- 天使卡兑奖成功后，卡片化为白金光羽进入兑奖区，余额数字在 500 ms 内更新。
- 兑奖接口失败时保留原卡和结果，不重复抽奖、不重复扣款。

## 6. 机器人与桌面道具

- 本卡不提供机器人动画，不得加入机器人队列；前端弹回、服务端拒绝。
- 风扇、垃圾桶、固定卡槽继续遵循全局桌面规则；动画不能绕过服务器对卡片状态的校验。
- 风扇吹动时只使用卡片通用物理动画，不触发死神徽记或结果演出。

## 7. 性能和无障碍

- 结果特效使用 CSS/Web Animations 加共享 Canvas 粒子，音效使用 Web Audio。
- 移动端粒子减半；持续掉帧时自动关闭 bloom、blur 和光波扭曲。
- 减少动态模式将三个结果均缩减为 150–200 ms 图标与结果文字淡入，不震动、不展开光翼。

## 8. 验收

- 70% 前只有通用刮擦效果，不能通过颜色、音效、延迟和资源请求判断结果。
- 所有好运等级下动画和固定概率逻辑完全相同。
- 机器人入口在 UI 和 API 两端均不可用。
- 动画跳过、刷新和兑奖重试都不会改变或重复发放结果。
