# 每日免费卡转盘设计 v0.1

> 状态：v0.3，卡池、权重、每日次数、展示方式和第 7/8 款排除规则均已确认；PC/手机概念图已生成，待视觉确认。

## 1. 功能定位

- 原“每日赠送一张刮刮卡”改为“每日获得一次免费转盘机会”。
- 转盘抽到的是一张完整刮刮卡，不是金币、碎片或折扣券。
- 免费卡不扣除金币，刮开、判奖、好运加成、机器人限制、兑奖和桌面生命周期与同品类普通购卡一致。
- 转盘只能抽到用户当前金币余额能够购买的卡，不通过历史最高余额或曾经解锁记录判断。
- 功能入口放在顶栏“今日任务”中，不永久占用刮奖桌面。

## 2. 可抽卡池

用户点击“开始转动”时，服务端根据当时余额生成一次不可变的卡池快照：

| 卡片 | 固定售价/门槛 | 进入卡池条件 |
| --- | ---: | --- |
| 《零钱小票》 | 50 | 当前余额 ≥ 50 |
| 《街角杂货铺》 | 1500 | 当前余额 ≥ 1500 |
| 《街机挑战券》 | 5000 | 当前余额 ≥ 5000 |
| 《黄金矿洞》 | 15000 | 当前余额 ≥ 15000 |
| 《火箭发射》 | 40000 | 当前余额 ≥ 40000 |
| 《深海打捞》 | 80000 | 当前余额 ≥ 80000 |
| 《永恒彩钻》 | 150000 | 永久不参与每日免费转盘 |
| 《放手一博》 | 300000 | 永久不参与每日免费转盘 |

- 免费转盘不会为了抽到某张卡先扣除该卡售价。
- 卡池快照生成后，即使用户在动画播放期间从其他设备消费金币，本次结果也不改变。
- 当前余额不足 50 时没有可抽卡，按钮显示“至少持有 50 金币后可转动”。正常情况下，每日登录赠送的 100 金币可以恢复资格。
- 余额增加后可刷新卡池预览；只有点击“开始转动”才真正锁定当日卡池。

## 3. 推荐抽取权重

不建议在所有可用卡中等概率抽取。高等级卡单张奖励量级很大，等概率会让每日免费奖励快速制造金币通胀，并削弱破产与恢复循环。

推荐使用以下基础权重；不在可购买范围内的卡权重被移除，剩余卡按比例重新归一化：

| 卡片 | 基础权重 | 前六款全部开放时实际概率 |
| --- | ---: | ---: |
| 《零钱小票》 | 30 | 31.91% |
| 《街角杂货铺》 | 22 | 23.40% |
| 《街机挑战券》 | 16 | 17.02% |
| 《黄金矿洞》 | 12 | 12.77% |
| 《火箭发射》 | 8 | 8.51% |
| 《深海打捞》 | 6 | 6.38% |
| 《永恒彩钻》 | 0 | 不参与 |
| 《放手一博》 | 0 | 不参与 |

示例：

- 余额 100：只有《零钱小票》符合条件，因此必定获得《零钱小票》。
- 余额 2000：前两款符合条件，实际概率约为 57.69% 和 42.31%。
- 余额 20000：前四款符合条件，实际概率依次为 37.5%、27.5%、20%、15%。
- 余额达到 80000 后，前六款全部进入卡池，实际概率固定为 31.91%、23.40%、17.02%、12.77%、8.51%、6.38%；余额继续增加不会让第 7、8 款入池。

转盘选择卡片的权重不受好运道具影响。好运只在获得卡片后，按各卡原有规则影响卡 1–6 的实际刮奖结果。

## 4. 转盘视觉

- 弹窗主体为桌面风格的黄铜机械转盘，深绿皮革内衬，与兑奖区和卡槽材质一致。
- 转盘固定展示八个品类。卡 1–6 中当前不可购买的卡显示锁图标和门槛；卡 7–8 固定显示“不参与免费转盘”，两类不可抽扇区都绝不成为落点。
- 扇区面积按基础权重设计，高等级卡扇区更窄；小扇区名称使用外侧引线标签，不能为了好看伪装成等概率扇区。
- 中央按钮显示“免费转动”，下方显示“今日 1/1”；使用后显示“今日已使用”。
- 转盘正面不显示刮刮卡内部中奖概率。点击“转盘规则”可查看本次可抽卡池和真实归一化抽卡概率。
- 不使用真钱、赌场筹码、老虎机、现金雨或“必中大奖”等视觉文案。

## 5. 转动动画

1. 用户点击“免费转动”。
2. 服务端在一个事务中校验当日次数、锁定卡池、抽取卡片品类、创建免费卡实例并消耗当日机会。
3. 客户端收到结果后开始转盘动画，转动 3–5 圈并在约 3.2–4 秒内自然减速到服务端指定扇区。
4. 落点后只突出实际抽中的卡片，显示“已放入购卡托盘”。
5. 用户关闭弹窗后，新卡从左上购卡托盘进入桌面安全空位；没有空位时留在托盘堆叠。

约束：

- 转盘动画不参与随机，不能通过刷新、断网、切换设备或强制关闭重新抽取。
- 不制作“差一点停在高级卡”专属回弹、磁吸、音效或慢镜头；指针只按统一减速曲线落到真实结果。
- 动画允许跳过；减少动态模式直接用 200 ms 淡入展示结果。
- 六种可抽结果素材使用相同预载策略，不得通过网络请求或加载时间泄露落点。
- 服务端创建卡成功但动画未播完时，下次进入直接显示“今日结果”和已创建的卡，不重复创建。

## 6. 免费卡记录

免费卡实例增加以下来源字段：

- `source = daily_wheel`
- `price_paid = 0`
- `nominal_price = 对应卡片固定售价`
- `wheel_date = Asia/Shanghai 自然日`
- `wheel_pool_snapshot = 当次可抽卡与归一化权重`
- `wheel_result = 抽中的 card_type`

金币流水不记录购卡支出，但游戏记录明确显示“每日转盘赠送”。统计报表需将付费购卡与免费卡分开计算，避免返奖率和用户净支出被免费卡污染。

## 7. 每日次数和时间

- 默认每天 00:00（Asia/Shanghai）刷新 1 次机会。
- 未使用机会不累计，避免长期不登录后一次性获得大量免费卡。
- 机会按 `user_id + date` 建立唯一约束，多设备同时点击也只能成功一次。
- 登录奖励 100 金币、刷盘子和免费转盘是三个独立的每日项目；领取顺序由用户决定。

## 8. 与其他系统的关系

- 好运：不改变转盘抽卡品类，只影响卡 1–7 的刮奖概率。
- 机器人：转盘只可能产生卡 1–6，这些免费卡均可进入机器人。
- 固定卡槽：免费卡与普通卡相同，可以保护和保存。
- 风扇/垃圾桶：免费卡仍可能被吹动或丢弃，丢弃后不补发。
- 排行榜：免费卡兑奖得到的金币正常计入当前余额。
- 破产恢复：用户次日可先领取 100 金币，再获得至少抽取《零钱小票》的资格。

## 9. 已确认决策

1. 每日转盘只抽取卡 1–6；《永恒彩钻》和《放手一博》永久不提供免费卡。
2. 卡 1–6 使用 30/22/16/12/8/6 的基础权重，未达到余额门槛的卡移除后按比例重新归一化。
3. 未使用的当日机会不累计到第二天。
4. 当前余额不足 50 时暂时不能转，领取每日 100 金币后恢复资格。
5. 转盘固定展示八款卡；未达门槛的卡显示锁，第 7、8 款显示“不参与免费转盘”。
