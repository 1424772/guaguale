# 第 7 款刮刮卡《永恒彩钻》设计草案

> 状态：v0.5。主题由黑钻正式调整为彩钻；售价、五项鉴定、八个等级、奖励边界和概率已确认；鉴定格只显示等级图标；主背景采用珍珠白、冰蓝、淡紫和微粉虹彩色系；彩钻概念图 v1 已完成；动态效果已形成首轮规范。

## 1. 定位

- 名称：《永恒彩钻》。
- 固定售价与动态购买门槛：150000 金币。
- 视觉等级：前七款中最高，定位为顶级珠宝鉴定证书；主背景使用珍珠白、冰蓝、淡紫和微粉虹彩，搭配铂金浮雕、贝母、小钻镶嵌和巨型透明彩钻。
- 卡面形态：横版，中央彩钻为非刮除主体；下方严格设置 5 个鉴定刮格。
- 支持手动刮奖和机器人刮奖。

## 2. 五项鉴定玩法

5 个鉴定刮格分别为：

1. 重量
2. 切工
3. 净度
4. 火彩
5. 稀有度

- 每项刮出八个等级中的一个。
- 鉴定格刮开后只显示该等级的图标，不在刮格内部显示等级名称或奖金文字。
- 五项全部刮开后，以其中最低的等级作为整张卡的最终鉴定等级。
- 服务端先抽取最终等级，再生成至少一项等于最终等级、其余四项不低于该等级的合法组合，并随机安排各项等级。
- 同一等级在五项中重复出现不会叠加奖金。
- 客户端只负责刮除、等级展示和视觉特效，开奖及组合生成由服务端完成。

## 3. 八级奖励边界

| 最终等级 | 兑奖金额 | 相对售价 | 实际盈亏 | 定位 |
| --- | ---: | ---: | ---: | --- |
| 裂纹级 | 30000 | 0.2x | -120000 | 严重亏损 |
| 工业级 | 75000 | 0.5x | -75000 | 中度亏损 |
| 珠宝级 | 120000 | 0.8x | -30000 | 小幅亏损 |
| 稀有级 | 150000 | 1.0x | 0 | 保本 |
| 精选级 | 157500 | 1.05x | +7500 | 赚一点点 |
| 典藏级 | 180000 | 1.2x | +30000 | 赚少一点 |
| 皇室级 | 270000 | 1.8x | +120000 | 赚多一点 |
| 永恒级 | 450000 | 3.0x | +300000 | 赚大一点 |

- 赚一点点控制为售价的 5%，与保本形成可感知但不过度的差异。
- 赚少一点控制为 1.2 倍，赚多一点为 1.8 倍，最高永恒级封顶 3 倍。

## 5. 光效与动态效果

### 5.1 卡片待机

- 彩钻做约 8–12 秒一轮的极缓慢视差偏转，不进行高速或完整旋转。
- 每 6–8 秒有一道细窄虹彩折射从彩钻表面扫过，持续约 1 秒。
- 铂金外框使用低亮度巡游微光，避免整圈持续闪烁。
- 背景小钻偶尔产生单点星芒，同屏高亮粒子不超过 6 个。

### 5.2 手动刮开

- 刮动轨迹产生铂金粉末和少量透明碎钻粒子，粒子快速下落并在约 0.6 秒内消失。
- 每个鉴定印章达到揭示阈值后，播放约 0.45 秒的等级色光环和一次短促折射。
- 光效颜色仅依据已经公开的等级，不对尚未刮开的结果提供暗示。

### 5.3 完成鉴定

- 五项全部刮开后，彩钻亮度随最终等级平滑提升，随后展示最终鉴定印章和兑奖金额。
- 裂纹级至稀有级使用克制的银蓝光；精选级和典藏级增加紫金折射；皇室级和永恒级使用金白光与少量钻石粒子。
- 永恒级可播放一次约 1.2 秒的环形棱镜爆光，但必须允许点击跳过。
- 结果动画只反映已经确定并公开的最终等级，不制造虚假接近中奖或隐藏概率暗示。

### 5.4 性能与无障碍

- 默认使用 CSS 变换、渐变遮罩和轻量 Canvas 粒子实现，不依赖大型 3D 引擎。
- 移动端降低粒子数量、光晕尺寸和纹理分辨率；低性能模式关闭实时折射，只保留预渲染高光。
- 遵循 `prefers-reduced-motion`：关闭视差、巡游光和粒子，只保留 150–200 毫秒淡入。
- 刮奖、判奖和兑奖逻辑不得依赖动画完成，跳过动画不影响状态。

## 6. 视觉与生产约束

- 只有重量、切工、净度、火彩、稀有度 5 个矩形区域使用铂金刮层；中央彩钻、等级阶梯和装饰边框都不是刮区。
- 五个鉴定格刮开后只能出现等级图标，不能在格内出现“裂纹级、稀有级、典藏级”等等级文字，也不能显示奖金数字。
- 底部固定图例按从低到高排列，使用“图标 + 等级名称 + 奖金”供用户对照；最终鉴定结果可在独立结果区域显示等级名称和兑奖金额。
- 八级图标必须使用不同轮廓，不能只依靠颜色区分：裂纹彩晶、粗面彩晶、切割彩钻、银环彩钻、星芒彩钻、典藏底座彩钻、皇冠彩钻、无限光环彩钻。
- 彩钻以透明晶体、珍珠白和冰银为主体，在切面中加入淡紫、浅蓝、微粉与克制的彩虹折射；不得保留黑色不透明钻石主体。
- 主背景色系以参考钻石的珍珠白、冰银、淡紫、浅蓝和微粉折射为准；深石墨与深紫仅用于文字对比和压住层次，不再以暖黑金作为主背景。
- 大部分装饰金属使用铂金和贝母质感，香槟金只保留为极少量暖色高光。
- 标题、售价、规则、五项名称、等级和奖励最终由 HTML/CSS 渲染。
- 不使用真实珠宝品牌、真实货币、赌场筹码或其他现金赌博视觉元素。
