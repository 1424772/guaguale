# 第 3 款刮刮卡《街机挑战券》设计草案

> 状态：v0.1。主题、售价、五档奖励和核心判奖规则已确认；基础概率与满级好运概率为待确认草案；概念图 v1 已生成待确认。

## 1. 定位

- 名称：《街机挑战券》。
- 固定售价与动态购买门槛：5000 金币。
- 视觉等级：90 年代街机厅主题，使用像素画、霓虹灯、CRT 扫描线和覆膜票券质感，品质高于《街角杂货铺》。
- 卡面形态：横版，中央设置 3 条横向赛道，每条赛道 3 格，共计 9 个刮格。
- 支持手动刮奖和机器人刮奖。

## 2. 三赛道判奖规则

- 只按同一条横向赛道判定；竖向和斜向的相同图案不参与判奖。
- 任意一条横向赛道刮出 3 个相同图案，即获得该图案对应的金币。
- 每张卡最多生成一条有效的“三同”赛道，因此最多兑付一个奖励，不累计多条奖金。
- 中奖卡：服务端先抽取奖励图案和有效赛道，再构造另外两条无三同赛道。
- 未中奖卡：三条赛道均不得出现三同。
- 客户端只负责呈现和刮除效果，开奖、布局生成与兑奖均由服务端完成。

| 图案 | 兑奖金额 | 相对售价 | 实际盈亏 | 结果性质 |

| 弹珠 | 2500 | 0.5x | -2500 | 中奖但亏损 |
| 拳套 | 4000 | 0.8x | -1000 | 中奖但亏损 |

最高兑奖金额为售价的 3 倍，符合当前整套卡片的上限要求。

## 4. 概率与金币经济草案

| 结果 | 无好运基础概率 | 满级好运概率 |
| --- | ---: | ---: |
| 街机皇冠三同 | 5% | 7% |
| 飞机三同 | 10% | 14% |
| 赛车三同 | 15% | 24% |
| 拳套三同 | 20% | 17% |
| 弹珠三同 | 20% | 18% |
| 无三同 | 30% | 20% |

- 无好运时理论平均奖励为 3630 金币，理论返奖率为 72.6%。
- 满级好运时理论平均奖励为 4548 金币，理论返奖率约为 90.96%。
- 无好运时获得不低于成本奖励的概率为 30%，满级好运时为 45%。
- 好运等级提升时，概率从未中奖和两档亏损奖励逐步转移到赛车、飞机和街机皇冠；卡片正面不印概率，独立规则详情中的数值必须与服务端实际开奖一致。
- 1–9 级好运的具体插值方式在统一数值配置阶段确定。

## 5. 概念图方向

- 深蓝黑色底搭配青色、洋红、电紫和暖黄色霓虹，维持清晰的街机层级感。
- 三条赛道分别使用红、蓝、紫作为辅助识别色，每条严格放置 3 个方形银色刮格。
- 五种图案统一使用原创像素画，依靠轮廓而非单纯颜色区分。
- 奖励图例放在卡片底部，购买价格与规则位于刮奖区之外。
- 正式网页实现中，标题、售价、规则和奖金文字由 HTML/CSS 渲染，图片只承担背景、边框与纹理。
